# TRUSTLINE 90-Second Demo Script

**Setup:** Start the frontend and backend, open Protection, and choose the built-in demo scenario tab. These examples are prewritten simulated transcripts; no audio is uploaded and no provider is contacted.

| Time | Demo action and narration |
|---|---|
| 0–10s | “TRUSTLINE helps a person pause during a pressured call. It reviews audio the user chooses to submit; it does not monitor cellular calls or detect cloned voices.” |
| 10–25s | Select **Digital Arrest and OTP Demand**. Point to the simulation banner and transcript. “This is an authored example, not a live recording.” |
| 25–40s | Show HIGH risk band, exact excerpt, tactics, and safe action. “The report shows which words triggered concern and what to verify next.” |
| 40–55s | Open **Explain it to my family**, switch between simple English and Hindi, and show the excerpt and three steps. Point out that nothing is sent automatically; copy is a user action. |
| 55–68s | Select **Legitimate Bank Security Call**. “Here, the transcript warns never to share an OTP and recommends calling the number on the card. This sample is prewritten; it demonstrates a protective-context example, not a proven detector result.” |
| 68–78s | Select **Family Emergency Impersonation** and show the pressure/isolation excerpt and verification action. |
| 78–90s | Open Evaluation. “This authored text pilot has 220 records across 35 scenario families. The deterministic rules report 97.5% overall recall, but 87.5% on a 44-record grouped re-partition, with three courier/customs misses. The development result is template-fit; none of these figures estimate real-world accuracy. AI-only and full-audio ablations are unavailable.” |

## Before presenting

- Confirm the simulation banner is visible and network monitoring shows no provider request for demo scenario selection.
- If demonstrating real upload, use an authorized recording, obtain explicit consent, and explain that audio/transcript are sent to configured providers.
- Do not call the LOW/MEDIUM/HIGH/CRITICAL bands probabilities. A LOW result does not prove safety.
- Describe the current detector as a prototype. The synthetic text pilot is not evidence of real-call performance or production safety.
- Show the production build and backend test results only as local build/test evidence, not as external validation.
